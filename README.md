

## Update: Elliptic Transaction Graph Analysis

This section adds the **Elliptic Data Set** processing pipeline to the dashboard resources. 

### Key Additions:
- **Automated Cleaning**: Renaming of 165 features and removal of inconsistent transaction records.
- **Graph Engine**: Construction of a directed `NetworkX` graph showing transaction flows.
- **Artifacts**: 
    - `cleaned_merged_data.csv`: Master dataset with human-readable labels.
    - `elliptic_graph.gexf`: Directed graph for dashboard visualization.
    - `data_decisions.log`: Processing audit trail.

### How to use these artifacts:
Load the `.gexf` file into the dashboard visualization engine to view illicit vs. licit flow clusters.
